#Отчет по лабораторной работе 1

В ходе выполнения лабораторной работы был создан и развернут статический сайт-портфолио с использованием генератора MkDocs. Работа выполнялась в несколько этапов, включающих настройку репозитория, локальную разработку и публикацию

На первом этапе был создан публичный репозиторий на GitHub. В настройках репозитория была активирована функция GitHub Pages с указанием источника публикации из каталога /docs ветки main. Репозиторий был клонирован на локальный компьютер

Для изоляции зависимостей проекта было создано и активировано виртуальное окружение Python, в которое затем был установлен MkDocs. Был настроен файл .gitignore для исключения из версионирования виртуального окружения и других служебных файлов

С помощью команды mkdocs new была создана начальная структура сайта. В процессе работы выполнялась настройка конфигурационного файла mkdocs.yml. В нем было задано название сайта, выбрана и подключена тема оформления. Тема material была выбрано по причине её фундаментальности, поскольку данная тема довольно популярна и следовательно имеет множество гайдов и плгинов, и стиля, подходящего для страницы резюме. Через параметр nav была реализована логичная и иерархическая структура меню для удобной навигации по сайту

Была создана структура страниц, соответствующая заданию: главная страница, страница «Об авторе» и раздел «Лабораторные работы», включающий отдельные страницы для каждой работы. В ходе работы было создано не менее пяти страниц. Локальное тестирование изменений выполнялось с помощью команды mkdocs serve

После завершения настройки и наполнения контентом была выполнена финальная сборка сайта в каталог /docs корня репозитория командой mkdocs build. Все изменения, включая исходные файлы и сгенерированные файлы из каталога docs, были зафиксированы в серии осмысленных коммитов и отправлены в удаленный репозиторий на GitHub

После публикации была проведена проверка доступности сайта в браузере по адресу, предоставленному GitHub Pages. Сайт успешно развернут и функционирует, все страницы открываются, навигация работает корректно. Таким образом, все поставленные в лабораторной работе цели были достигнуты, продемонстрировано понимание процессов генерации статических сайтов, организации документации и публикации проектов на GitHub Pages.
